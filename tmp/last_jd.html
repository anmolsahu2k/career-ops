Software Engineer

Department: Broadcast Sports International
Location: Baltimore, MD
START YOUR APPLICATION

Overview

This position is responsible for the design, development, testing, and ongoing support of software systems that enable and enhance advanced broadcast, video, and RF-based hardware platforms. The role focuses on building reliable, high-performance software that interfaces closely with custom electronic systems, including embedded processors, control interfaces, and video transport architectures. Responsibilities span the full software development lifecycle, from requirements definition and architecture design through implementation, verification, deployment, and long-term maintenance.

Essential Job Functions

  • At least 5 years experience in Embedded application development in C/C++ and Assembly Language on embedded 8-bit/32-bit processors
    • Video, audio, RF / UHF processing and control
    • Multithreaded Programming (FreeRTOS or equivalent)
    • Bare-metal programming
    • Real-time programming
    • User interface design
    • Multi-processor system programming/inter-processor communications
    • Bringing up custom boards
      • Bootloader development
      • Understanding of schematics
      • Ability to use hardware test equipment (oscilloscopes, logic analyzers, etc.)
    • SPI, I2C, RS-232/485, CAN bus, Ethernet interfaces
    • ARM/Atmel AVR/STM32
  • At least 5 years experience in Desktop Application development
    • System level control GUI design for Video, Audio, and RF systems
    • System level testing and troubleshooting
    • Test application development
    • C#/C++, Python
    • .NET Development
    • WPF, Windows Forms, ASP.NET
    • Software configuration management: Git

Preferred Experience

    • Linux Application programming
    • Digital Hardware design
    • FPGA development in VHDL/Verilog
    • DSP programming
    • Wireless communications
    • Familiarity with RF test equipment, spectrum analyzers, etc.
    • Background in broadcast or digital video
    • Python development
    • Exposure to any of the following technologies:
      • Wireless communications in UHF and microwave bands
      • Video compression, MPEG-2, H.264, H.265
      • Audio compression, MPEG-1 layer 2, MP#, AC3, AAC

Job Requirements

  • Bachelors degree in a Computing and/or Engineering related field or documented certifications as well as equivalent experience.
  • Occasional (up to 25% of time on job): Sitting, Standing, Lifting (max. 10-25 lbs.), Reaching, Repeated Bending Frequently (25 75% of time on the job): Repetitive Finger Movements, Near Vision
