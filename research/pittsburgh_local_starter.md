## Verification protocol (do this for each Tier 1 before applying)

1. Open the careers URL — confirm it loads, and a 2026 intern req exists
2. Check posting date — anything older than 60 days may be stale; newly posted is best
3. Read sponsorship language — look for "no sponsorship offered" red flags or "F-1 / CPT / OPT acceptable" green flags
4. LinkedIn search: `[Company] AND CMU AND Engineer` — find a 2024–2026 alumni
5. Send Track A2 alumni message BEFORE submitting the application (warm intro > cold app)
6. Apply via the careers page; reference the alumni contact in cover blurb if applicable
